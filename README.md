# 🎧 ZATIFY

Website musik sederhana — cari, dengarkan, dan simpan lagu favoritmu langsung dari browser.

Dibuat sebagai proyek tugas HTML/CSS/JavaScript (vanilla, tanpa framework/library).

## ✨ Fitur

- **Home** — halaman utama dengan lagu-lagu unggulan
- **Daftar Music** — semua lagu dari API, bisa diputar langsung dan diurutkan A-Z / Z-A
- **Search** — cari lagu berdasarkan judul atau nama artis
- **Favorite** — simpan lagu favorit, tersimpan otomatis di browser
- **Masukan** — form buat kirim saran/kritik soal web ini

## 🛠️ Dibangun dengan

- HTML5 (elemen semantik: `header`, `nav`, `main`, `section`, `article`, `footer`)
- CSS3 murni (Flexbox, tanpa library/framework)
- JavaScript vanilla (DOM manipulation, `fetch()` ke REST API, `localStorage`)

## 📂 Struktur Proyek

```
├── index.html      (Home)
├── music.html      (Daftar Music)
├── search.html     (Search)
├── favorite.html   (Favorite)
├── feedback.html   (Masukan)
├── style.css
├── index.js
├── music.js
├── search.js
├── favorite.js
└── feedback.js
```

## 🚀 Cara Menjalankan

1. Download / clone repo ini
2. Buka `index.html` di browser (disarankan pakai extension **Live Server** kalau di VS Code)
